# 文档档案

本目录保存历史材料，仅用于追溯决策，不是当前规则或实现依据。

- `requirements/`：初始需求、历次更正、旧版 SRS，以及已经被权威规则取代的《四色牌操作说明》《四色牌游戏流程说明》。
- `plans/`：已经执行完毕的阶段性设计或实施方案。

需要确认当前行为时，请返回上一级的 [文档入口](../README.md)。历史内容若仍然有效，应整理后写入对应权威文档，不应从档案直接链接为规范。

归档文档正文保留其形成时的说法，因此可能包含已经失效的规则、目录路径和界面草图。此类内容只代表历史背景；当前规则分别见 [游戏规则](../GAME_RULES.md)、[产品与体验规范](../PRODUCT_UX.md) 和 [系统架构](../ARCHITECTURE.md)。

# 邀请链接复制失败兜底设计

## 背景

普通 HTTP 局域网、较旧的手机浏览器或受限 WebView 可能同时拒绝 Clipboard API 和 `execCommand("copy")`。此前最后退回系统 `prompt`，其字号、按钮、焦点和关闭行为均不受页面控制，对老年玩家不够友好。

## 方案比较

- 仅显示失败提示：实现简单，但玩家仍无法取得邀请链接。
- 直接调用系统分享：部分浏览器不可用，而且把“复制”改成了另一种操作。
- 站内链接弹层：保留原任务语义，并能控制字号、触控、焦点和安全关闭。

采用站内弹层。自动复制成功时仍使用原有绿色提示；只有两级复制都失败才显示兜底。

## 交互

- 弹层显示只含 `roomId` 的邀请 URL，不带 `playerToken`、`hostKey` 等身份凭据。
- 打开后自动聚焦并全选只读链接，提示玩家长按后选择“复制”。
- 提供“选中链接”和“关闭”两个清晰按钮；在低像素手机上保持至少 48px 高。
- Tab/Shift+Tab 焦点留在弹层内，Escape、遮罩和“关闭”均可退出。
- 关闭后焦点回到原“复制邀请”按钮；离开等待房间时自动清除弹层。
- 弹层随横向游戏画布旋转，不使用脱离画布坐标系的传送节点。

## 验收

- 375×667 旋转画布内不越界，文字至少 16px，链接可长按选取。
- 自动复制成功和失败路径都有端到端覆盖。
- 失败路径不得调用系统 `prompt`，不得泄露房主或玩家凭据。

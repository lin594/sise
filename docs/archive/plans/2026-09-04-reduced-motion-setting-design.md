# 游戏内减少动态效果设计

> 状态：已实现并归档。当前行为以 `PRODUCT_UX.md`、`ARCHITECTURE.md` 和 `TESTING.md` 为准。

## 问题

当前界面会尊重操作系统的 `prefers-reduced-motion`，但游戏内没有可发现的入口。部分老年玩家不知道系统设置的位置，也可能只希望在牌局中减少飞牌、翻转、闪烁和顺滑滚动。此前试玩已经出现“动画影响节奏、像重复播放”的反馈，因此仅依赖系统偏好不足以覆盖实际使用场景。

## 方案比较

- 只继续跟随系统：代码最少，但设置不可发现，也无法只针对本游戏调整。
- 提供“快 / 标准 / 慢”三档速度：选择看似丰富，却会把服务端思考时间、信息停留和装饰动画混在一起，容易让玩家误以为规则节奏发生变化。
- 提供“减少动态效果”开关：只停止非必要移动和循环闪烁，保留状态文字、牌面和必要阅读停留；服务器决策时间不变。

采用第三种方案。它与系统偏好叠加：任一方要求减少动态，界面都采用静态表现。游戏内开关默认关闭，避免改变既有玩家体验，并保存在现有显示偏好中。

## 行为

- 设置面板新增“减少动态效果”开关，说明为“关闭飞牌、翻转和循环闪动”。
- 开启后，牌桌、声明、操作坞、结算和弹层的非必要动画与过渡立即缩短至近乎零；发牌飞行动画和定庄牌飞行动画不再显示。
- 定庄牌揭晓、操作结果和错误提示仍保留原有阅读时间，不能因为动画关闭而跳过信息。
- 手牌“前翻 / 后翻”与声明手牌翻页改为立即滚动；牌序、选择和服务端状态不变。
- 系统已经设置减少动态时，即使游戏内开关关闭，也继续使用减少动态表现。
- 新字段加入 `GameDisplayPreferences`，旧本地偏好缺少该字段时安全迁移为 `false`。

## 验收

- 320×568 自动旋转设置面板中入口可滚动到，按钮和说明完整可读，滚动提示仍准确。
- 点击后根布局立即出现减少动态状态，偏好写入本地存储，刷新后保留。
- 开启状态下 CSS 动画时长不超过 0.01ms，翻页使用即时滚动；关闭后恢复普通动画。
- Playwright 同时覆盖显式开关和操作系统 `prefers-reduced-motion`，生产构建、全量回归和 iMac 公网烟测通过。

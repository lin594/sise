# 本人回合顶部设置控件稳定设计

## 背景与实测

568×320 的实测牌桌中，本人需要选牌或响应时，顶部“设置”按钮会改名为黄色“先操作”，同时保持禁用。右侧操作坞已经用更大的“该你操作了”和“先选牌 / 出牌”承担主行动引导，因此顶部又出现一个不能点击的“先操作”会形成第二个视觉焦点。对不熟悉禁用态的老年玩家，它尤其像一个失效的主按钮，也破坏了顶部只放全局控制的稳定心智模型。

## 方案比较

### 方案 A：保留黄色“先操作”

提示最显眼，但与真正操作坞竞争注意力，文字还会在回合之间改变，容易让人先去点错位置。

### 方案 B：本人回合隐藏设置

能减少干扰，但顶部按钮位置会跳动，记录与退出随之移动，增加误触风险；玩家也无法理解设置为何消失。

### 方案 C：固定显示“设置”，用安静的锁定态表达暂不可用

采用此方案。设置始终保留相同图标、名称、尺寸和位置；本人必须操作时继续禁用以避免面板遮挡决策，但取消黄色警示边框，改用中性低对比样式。视觉界面不再重复“先操作”，完整原因放在 `aria-label` 和 `title` 中；真正的行动引导只由右侧操作坞承担。

## 行为与可访问性

- 非本人回合和声明阶段按原逻辑打开设置。
- 本人响应或弃牌阶段，按钮仍是原生 `disabled`，可见文字始终为“设置”。
- 禁用按钮不使用黄色、绿色或红色，不模拟主操作；图标与文字仍保持足够辨认度，避免看起来像页面坏掉。
- 无障碍名称和鼠标提示使用“完成当前操作后可打开设置”，说明限制原因，不把无效控件放进键盘顺序。
- 若设置或规则面板已经打开，本人操作窗口到来时仍自动关闭，并把焦点移到第一张合法手牌或第一个合法动作。
- 记录和退出按钮的行为、顺序与位置不变。

## 验收

- 568×320、320×568 自动旋转、667×375 和 1280×720 中，本人操作时顶部按钮仍显示“设置”，不显示“先操作”。
- 设置按钮保持禁用，样式为中性且不比右侧主操作更醒目；三个顶部控件的位置不因回合变化而移动。
- 按钮无障碍名称包含“完成当前操作后可打开设置”。
- 本人操作结束后，设置按钮原位恢复可用；打开的设置/规则层在新操作到来时仍自动关闭且焦点正确转移。

## 非目标

- 不允许本人操作期间打开设置。
- 不改变操作坞提示、倒计时、响铃或震动。
- 不调整服务端回合和动作协议。

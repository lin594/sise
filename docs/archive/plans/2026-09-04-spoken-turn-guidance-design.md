# 轮到本人时的语音提示设计

> 状态：已实现并归档。当前行为以 `PRODUCT_UX.md`、`ARCHITECTURE.md` 和 `TESTING.md` 为准。

## 问题

当前新的本人操作窗口会响铃、震动并修改页面标题，但这些信号只能表达“有事情发生”，不能告诉视力下降或不熟悉流程的玩家下一步该做什么。操作坞已有准确文字，因此语音应复用同一权威状态，用一句短提示补充说明，而不是持续解说整局。

## 方案比较

- 持续播报出牌、吃碰和结算：信息最全，但会与真人交谈、读屏软件和牌局节奏冲突。
- 用语音替换现有提示音：入口较少，但会强迫已有玩家改变习惯，也失去震动等安静提醒。
- 新增独立的“语音提示轮到我”开关：默认关闭，需要时与响铃/震动叠加；只播报本人的新决策窗口。

采用第三种。语音属于渐进增强，不改变服务端状态、响应顺序或倒计时。

## 行为

- 设置面板新增“语音提示轮到我”，说明为“轮到你时读出下一步”，偏好保存在现有 `sise_game_display_preferences_v2` 中。
- 新偏好默认关闭；旧本地偏好缺少字段时迁移为关闭，避免网页突然说话。
- 每个新的本人决策键最多播报一次：弃牌时提示“先选一张手牌，再点出牌”；动作响应时根据服务端当前可用动作读出“胡、开、碰、吃、抓、过”中的实际选项。
- 将牌或金条不可过时，明确提示“这张特殊牌不能过，请选择吃法”。不播报其他玩家回合、动画或历史记录。
- 使用浏览器原生 `speechSynthesis`，语言为中文、语速略慢；新决策到来前取消本应用尚未结束的旧播报，避免两句话重叠。
- 浏览器不支持语音时设置显示“此浏览器不支持”并不可点击；响铃、震动、视觉提示和牌局操作照常工作。
- 开关在当前决策开始后才开启时，可立即播报当前提示；同一决策的普通状态刷新不得重复播报。

## 验收

- 320×568 自动旋转设置面板中入口可滚动到，说明、开关状态和“不支持”状态完整可读。
- 开启后进入新的弃牌或响应窗口只产生一次正确中文播报；后续状态刷新不重复，新决策会再次播报。
- 关闭后不播报；刷新页面后偏好保持。旧偏好安全补全为 `false`。
- 缺少 Speech Synthesis API 时不抛错、不影响提示音、震动或动作提交。
- 客户端构建、完整 Playwright 回归与 iMac 公网烟测通过。

# 老旧手机牌桌计数可读性设计

## 问题

568×320 实机等效画布中，核心牌字和动作按钮已经清晰，但几项高频判断信息仍明显偏小：对手余牌“20张”和机器人“电脑”标识约 10.6px，本人“手牌（20张）”在紧凑断点约 9.9px，手牌翻看范围约 12px。它们不是装饰文字：余牌影响判断，身份帮助区分真人和电脑，范围用于确认是否已经看完手牌。老年玩家需要反复辨认时，会抵消大牌面的收益。

## 方案

- 对手余牌与机器人身份在老旧小屏使用至少 13px 的高对比粗体。
- 本人手牌计数和实时/声明手牌可见范围至少 13px。
- 保留姓名独占首行、身份徽章在下一行的紧凑布局；必要时压缩徽章内边距，不缩回文字。
- 不改变牌面尺寸、首屏牌数、横滑/前后翻行为、服务器手牌数或座位数据。

## 验收

- 568×320 和 320×568 自动旋转画布中，三家余牌数字和电脑标识至少 13px且完整可见。
- 本人手牌计数、实时翻看范围和声明翻看范围至少 13px。
- 左右玩家卡、顶部玩家卡、手牌工具栏和操作坞不重叠或横向溢出。
- 仍能在老旧小屏首屏看到至少八张手牌，所有翻看按钮和现有无障碍名称保持不变。

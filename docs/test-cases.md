# 四色牌验收用例

当前可验收范围包括单人练习和好友同桌；联机匹配、账号登录不在当前范围内。

## 好友房

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| L-01 | 创建与邀请 | 房主创建好友房并复制链接 | 链接只含 `roomId`，创建者默认占首席 |
| L-02 | 自由选座 | 受邀者打开链接并点击空座 | 服务端原子占座，其他客户端实时看到结果 |
| L-03 | 机器人配置 | 房主在两个空座添加机器人并调整强度 | 强度按座位同步为 0–100，非房主操作被拒绝 |
| L-04 | 开局门槛 | 留有空座或离线真人时点击开始 | 禁止开局并显示具体原因；四席就绪后可开始 |
| L-05 | 断线恢复 | 等待大厅真人刷新后在 60 秒内重连 | 使用房间级 token 恢复原座；超时后座位释放 |
| L-06 | 房主转让 | 房主断线且仍有在线真人 | 权限转给座位序号最小的在线真人 |
| L-07 | 私有手牌 | 两名真人进入同一局 | 各客户端只收到自己的手牌和动作候选 |
| L-08 | AI 强度 | 同一局面多次运行低/高强度机器人 | 高强度选择高评分候选的比例显著更高，所有动作均合法 |

## 规则逻辑

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| R-01 | 弃牌区全公开 | A主动弃出“黄马”或抓后过出“黄马” | B/C/D均看到A弃牌区顶部出现“黄马” |
| R-02 | 吃操作前置 | B待响区“红将”，A手有“红士”“红象”，集体询问无人响应 | A进入模式1后，“吃”按钮点亮 |
| R-03 | 面板双状态 | A待响区初始牌，无人响应，A点“抓” | 面板切换为“胡/开/碰/吃/过” |
| R-04 | 抓与过语义 | 模式1点“抓”，模式2点“过” | 抓：抓新牌并重新进入集体询问；过：新牌入A弃牌区并移至下家待响区 |
| R-05 | 单将胡牌校验 | 手牌“红将+红士+红象”，待响区“红炮” | 胡失败（不可拆解） |
| R-06 | 抓后再询问 | `local_upper` 阶段点“抓” | 新抓牌进入 `collective` 询问；无人响应后进入 `local_draw` |
| R-07 | 碰/坎结算区分 | 胡牌响应牌 + 手牌两张同面牌组成三张 | 结算按“碰”展示和计分，不按暗坎 |
| R-08 | 胡牌最高分拆解 | 同一批牌存在低分/高分两种合法拆解 | 结算选择高分拆解 |
| R-09 | 开局手牌遮挡 | 单人练习开局发牌动画期间 | 不应先显示完整手牌再播放发牌动画 |
| R-10 | 机器人保留特殊牌 | 任意强度机器人在真实房间流程中抓到四色将或五种金条 | 胡牌和合法开仍优先；否则流程层必须把牌收入机器人本人的将/金条区，不得传给下家或进入弃牌区 |
| R-11 | 互付结算文案 | 机器人2向玩家的金条开付18分 | 显示“机器人2 付 金条开：+18分”，名称和“付”之间留空格 |

## 前端专项

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| F-01 | 竖屏横向画布 | 375×667 手机竖屏或锁定竖屏打开页面 | 无方向遮罩；应用按 667×375 横屏画布旋转显示且可完整操作 |
| F-02 | 按钮点亮 | B待响区“黄车”，A手无匹配 | A界面“胡/开/碰”灰显，保留可执行按钮 |
| F-03 | 弃牌区展示 | A连续弃3张牌 | B/C/D均看到A弃牌区完整3张牌面 |
| F-04 | 明示区高亮 | A完成一次吃牌 | 响应牌带金边与星标，高亮动画可见 |
| F-05 | 触屏优化 | 小尺寸手机点击“吃”或“出牌”按钮 | 按钮随有效画布自适应，手指可稳定触发且不挤占牌桌 |
| F-06 | 模式入口 | 进入大厅查看模式卡片 | “单人练习”“好友同桌”可用；“联机匹配”显示即将开放 |
| F-07 | 声明面板 | 开局发牌后进入声明阶段 | 系统预选全部合法鱼与剩余最大暗坎；玩家可整组取消鱼、直接选择暗坎数量，并通过汇总按钮一次确认 |
| F-08 | 紧凑确认出牌 | 667×375 横屏进入正式牌局，反复点击或双击一张普通牌 | 自适应手牌宽约40–44px、间隔约2px、字形不小于约22px，首屏约9–10张并可横滑；牌只被选中，右侧操作坞从“先选牌”变为“出牌”后才可提交 |
| F-09 | 操作坞 | 手机出现胡/开/碰/吃/过五个动作，随后进入弃牌阶段 | 响应动作以 3×2 网格完整显示；弃牌阶段同一位置显示确认按钮；控件随空间调整且不裁切、不误触 |
| F-10 | 全流程滚动 | 手机依次打开大厅、规则、声明、候选和结算 | 页面无全局溢出；声明手牌保持单行预览，候选区可横滑，确认按钮始终位于安全区内 |
| F-11 | 中央信息精简 | 定庄完成、普通等待、待响牌出现 | 不显示抽牌者或重复庄家姓名；唯一庄家姓名旁有“庄”和定庄牌；八层象形牌堆居中偏上并显示准确余量，待响牌同轴偏下，无待响时没有占位框 |
| F-12 | 顶部控制与个人退出 | 在声明、对局和结算阶段查看顶栏并打开设置，随后取消/确认退出 | 顶栏只显示“四色牌”、设置和退出，且不遮挡任何牌局信息；取消后留在牌局，确认后清凭证、停止重连并回到模式大厅 |
| F-13 | 全牌区显示模式 | 分别切换“我的牌”和“桌面牌”的大字/自适应/长牌并刷新 | 对应声明、手牌、候选、牌组、流水、待响、定庄、动画及结算牌即时统一变化；默认自适应，刷新保留且旧偏好正确迁移 |
| F-14 | 座位显示方向 | 从默认逆时针切到顺时针再切回 | 左右玩家及其牌组、流水、回合提示和飞牌动画镜像；自己、对家、服务器座位号及实际行动顺序不变 |

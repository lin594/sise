吃牌由浏览器在本地多人服务的练习房操作。测试场景为 `chi_local_upper_zu4`。在 568×320、844×390、390×844、1440×900 分别选择三色组合再确认，检查服务端公开区恰好收进白卒、红兵、黄兵，绿卒依然可见。窄屏的确认按钮和手牌区分开，更多吃法可横向滑动。844 和 1440 的截图另套用与[牌桌改版前后对照](../paper-table/README.md)相同的固定牌组和名字，便于比较同一桌况。

开启纸牌音效后，出牌和收组各有一种声音。浏览器回归记录实际开始播放的音频源，覆盖默认关闭、手势开启、静音、重复状态、掉线和重连。音效通过 Web Audio 生成。

## 真人体验记录

本次证据来自自动化浏览器和固定测试房。安排线下试玩时，可让牌友在不提示的情况下进练习、辨认来牌来源、吃三色并保留绿卒，最后在结算中找出本局收付。记录设备、是否自行完成、哪一步误触或需要提示，以及牌友对纸牌声的原话。当前没有真人试玩记录。

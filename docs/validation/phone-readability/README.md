# 同一手牌在手机和折叠屏上的显示

以下画面取自本地 Chrome 触屏视口。通过测试服务设置 `chi_local_upper_full_hand` 牌局，同一位玩家有 20 张手牌，桌上的来牌为红帥。在同一局中依次改变视口和显示偏好，最后点击「吃」。视口宽高单位为 CSS 像素。

| 可用尺寸 | 实装画面 | 这局怎样看牌 |
| --- | --- | --- |
| 568 × 320 | [长辈版](chi-568x320-senior.webp) | 下方保留大字手牌，用左右按钮翻到后面的牌。 |
| 844 × 390 | [普通模式](chi-844x390-standard.webp) · [长辈版](chi-844x390-senior.webp) | 普通模式可看全手牌，长辈版用大字、分页和更大的确认按钮。 |
| 690 × 820 | [展开内屏长辈版](chi-690x820-senior.webp) | 内屏保持竖向，20 张手牌分两行显示，可以直接点最后一张。 |

另一组实操从同局完成吃牌，再在小屏上选择黄仕。[查看出牌前的确认画面](discard-568x320-senior.webp)。

浏览器测试也覆盖从外屏折叠到内屏时保留选牌、改选后按牌名确认、窄屏点击安装和长辈版两个相邻入口。截图与测试均为浏览器验收，未进行实体折叠机或长辈玩家试用。

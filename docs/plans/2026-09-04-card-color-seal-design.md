# 牌面颜色文字印设计

## 问题

当前牌面用黄、红、绿、白底色表达花色，读屏名称也包含颜色，但看得见的牌面没有非颜色线索。老旧屏幕偏色、环境反光或玩家色觉减弱时，仅靠底色会增加辨认负担；金条又与红色牌同为红底，更容易混淆。

## 方案

在统一 `Card` 组件内增加一个不参与读屏重复朗读的小型文字印：四色分别写“黄 / 红 / 绿 / 白”，金条写“金”。沿用实体四色牌的简洁牌面，不增加图例或要求玩家记忆图形编码。

- 大字牌把文字印放在左上角，与手牌右上角的“留 / ✓ / 候选”状态徽章错开。
- 长牌把文字印放在上下两个倒转主字之间，保留最早的双头牌面结构。
- 极小定庄牌等 `xs` 牌面缩小文字印，但仍保留可见字符；手牌等主要牌面使用更大的印章字号。
- 文字印使用浅色纸章、深色字和细边框，在五种底色上都保持稳定对比。
- 现有完整读屏名称不变，避免辅助技术重复朗读颜色。

## 验收

- 大字、长牌和金条都显示正确文字印，牌面主字不被覆盖。
- 568×320 与 320×568 自动旋转画布中，手牌主字尺寸、首屏牌数、翻页和点击区域不退化。
- 待响应、定庄、公开牌组、动画和结算等所有复用 `Card` 的区域自动获得同一标记。
- 客户端构建、移动端牌面回归和 iMac 真实部署烟测通过。

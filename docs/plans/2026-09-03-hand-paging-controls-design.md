# 小屏手牌翻看控件设计

## 背景

手牌在小屏上保持单行横滑，并额外提供左右翻看按钮。当前按钮约 26–32px，且只显示细小箭头；自动化虽然验证了它们存在，却不足以证明手抖、视力弱或不熟悉横滑的玩家能够稳定理解和点击。568×320 实机尺寸截图中，这两个控件明显小于牌面与主要动作按钮。

## 方案比较

- 只放大箭头：改动最小，但箭头仍要求玩家自己理解方向和用途。
- 取消按钮、只保留手势：节省空间，但对不熟悉横滑的老年玩家不友好。
- 使用“‹ 前翻 / 后翻 ›”文字按钮并扩大触控区：占用少量工具栏宽度，但含义直接，也保留触摸横滑。

采用第三种。按钮只在手牌确实溢出时出现，既不挤占无需翻页的布局，也不改变选牌和出牌协议。

## 交互与布局

- 左按钮显示“‹ 前翻”，右按钮显示“后翻 ›”；读屏名称继续使用完整的“向左翻看手牌 / 向右翻看更多手牌”。
- 667×375 和 568×320 下按钮触控区至少 44×34px，文字不小于 12px；标准桌面至少 48×36px。
- 到达开头或末尾时对应按钮保持可见并禁用，颜色、边框和原生 disabled 语义共同表达状态，避免布局跳动。
- 每次移动约当前可见宽度的 72%，保留前后牌的视觉上下文；减少动态偏好下取消平滑动画。
- 保留直接触摸横滑，点击翻看不得选牌、弃牌或改变手牌顺序。
- 工具栏允许左侧张数提示收缩，但不得遮挡翻看按钮；568×320 下仍至少完整显示 8 张 40×52px 手牌，操作坞不得被挤出屏幕。

## 验收

- 667×375 与 568×320 均能看到完整的“前翻”“后翻”文字，按钮尺寸达到上述下限。
- 首屏左按钮禁用、右按钮可用；后翻后横向位置明显变化、左按钮启用，手牌 ID 和选中状态不变。
- 连续翻到末尾后右按钮禁用，前翻可回到开头。
- 触摸横滑、键盘 Tab/Enter 和读屏名称保持可用。
- 页面宽高无全局溢出，原有首屏牌数、牌面字号和动作按钮尺寸回归通过。

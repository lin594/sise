# 非本人回合操作坞精简设计

## 背景与实测

在 568×320 和 667×375 的实际牌桌截图中，非本人回合的右侧操作坞仍显示一整排灰色“胡 / 开 / 碰 / 过”按钮。虽然按钮不可点击，但它们保留了强烈的控件外观；玩家既要判断当前座位和中央箭头，又要理解这些按钮为何不能使用。对视力下降、操作经验较少的老年玩家而言，这类“看起来能点但不能点”的假操作会增加犹豫，也容易让人误以为游戏卡住或自己漏掉了一步。

操作坞本身不能在等待时消失：固定位置有助于建立肌肉记忆，而且完全收起会让手牌区域和牌桌随回合变化而跳动。需要精简的是内容，而不是布局锚点。

## 方案比较

### 方案 A：保留全部禁用按钮并补充原因

可以维持现状，但需要逐个解释按钮为何不可用，信息量更大，也不能消除按钮带来的错误操作暗示。

### 方案 B：等待时折叠整个操作坞

能腾出空间，但本人回合到来时牌桌会突然重排，按钮位置也不稳定，反而更容易误触。恢复和动画阶段还需要重新决定占位方式。

### 方案 C：固定操作坞，等待时只显示状态

采用此方案。非本人回合保留同样大小与位置的操作坞，但用一个非按钮等待卡替代所有灰色动作按钮。卡片用大字说明“某某正在操作”，并补充“轮到你时会提醒”。本人拥有合法响应或进入弃牌阶段时，才渲染真实动作按钮；断线时继续使用已有的“操作已暂停”状态。

## 界面与状态

- 非本人回合不渲染 `.btn` 动作按钮，也不显示可点击外观。
- 等待卡使用 `role="status"` 和礼貌播报，主要文字为“玩家名正在操作”，辅助文字为“轮到你时会提醒”。玩家名未知时显示“等待其他玩家”。
- 等待卡保持高对比但降低视觉优先级，不使用警告黄、危险红或主操作绿；可以使用三个静态圆点表达等待，不依赖动画传达含义。
- 本人可响应时仍显示“该你操作了”、倒计时或“练习不限时”以及胡、开、碰、吃、过等真实按钮。
- 本人弃牌时仍显示“先选牌 / 出牌”；网络中断或同步未完成时仍优先显示“操作已暂停”。
- 操作坞外框尺寸和牌桌网格不变，切换状态不会推动手牌、中央牌堆或玩家座位。

## 可访问性与异常处理

- 等待卡不是 `button`，不进入 Tab 顺序；键盘用户不会在无效动作之间逐个停留。
- 状态切换到本人操作后，现有焦点管理继续把焦点送到第一个合法动作或第一张可选手牌。
- 等待文案只在当前玩家变化时自然更新，不增加高频响铃或震动；轮到本人仍沿用已有一次性提醒偏好。
- 若连接中断、正在重连或私有手牌未同步，暂停状态优先于普通等待状态，避免把网络问题误写成其他玩家仍在操作。

## 验收

- 568×320、667×375、320×568 自动旋转和 1280×720 下，非本人回合的操作坞内没有任何 `.btn`，只显示一张完整可见的等待卡。
- 等待主文字在 568×320 下不小于 15px，辅助文字不小于 12px；卡片与手牌、顶栏、牌桌均不相交。
- 等待卡的无障碍文字包含当前玩家姓名与“轮到你时会提醒”，自身不进入 Tab 顺序。
- 切到本人响应后，等待卡消失，合法动作按钮立即出现且原有触控尺寸不变。
- 切到本人弃牌后，显示“先选牌”；选牌后显示“出牌”。
- 断线时不显示普通等待卡，继续显示“操作已暂停”和自动恢复说明。

## 非目标

- 不改变服务端回合、动作候选、倒计时和机器人策略。
- 不扩大底部操作坞，也不挪动手牌或中央牌堆。
- 不为等待状态增加循环动画、声音或新的偏好设置。

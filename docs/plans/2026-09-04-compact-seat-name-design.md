# 小屏座位姓名可读性设计

## 问题

在 667×375 和 568×320 的有效横屏画布中，左右座位的姓名、电脑标识、余牌数和庄家信息被放在同一行。固定徽章会把姓名压缩到一两个字，座位容器还可能产生横向滚动；本人姓名末尾追加“（你）”后也容易只显示半截。老年玩家因此难以确认谁正在操作。

## 方案比较

- 缩小字号或徽章：能维持单行，但直接损害主要受众的可读性，不采用。
- 隐藏电脑、余牌或庄家标识：腾出空间，但会丢失牌局决策信息，不采用。
- 姓名单独占一行、徽章在下一行：保留全部信息，只使用侧边座位本来就有的纵向空间，采用。

## 决定

- 仅在紧凑牌桌中把左右座位的姓名放到独立首行，电脑、余牌和庄家组合在下一行自然换行。
- 左右座位禁止横向滚动，公开牌组过多时只允许纵向滚动。
- 本人姓名不再把“（你）”拼进标题，改为独立、醒目的“你”徽章，让姓名获得稳定宽度；无障碍摘要继续明确这是本人的位置。
- 保持顶部对家座位的现有单行布局，因为它有足够横向空间。

## 验收

- 667×375 和 568×320 下，左右玩家姓名至少获得可辨认的宽度，座位不存在水平溢出。
- 本人常见三至四字昵称完整可见，“你”标识独立可见。
- 电脑身份、余牌数、庄家牌、当前回合和临时托管状态仍可见且不互相覆盖。
- 桌面布局不被紧凑样式改变。

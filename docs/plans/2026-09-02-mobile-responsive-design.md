# 移动端横屏画布与响应式设计

## 目标

手机以横屏牌桌为唯一游戏画布。系统处于竖屏或锁定竖屏时，不显示方向提示，而是交换有效宽高并将应用顺时针旋转 90°；用户横拿手机后仍可完整触控。最低有效画布为 667×375。

## 布局

- 有效宽度不超过 960px 或高度不超过 500px 时进入紧凑模式；宽度不超过 720px 或高度不超过 380px 时进入超紧凑模式。
- 声明、对局和结算阶段预留独立顶部控制栏：左侧为“四色牌”，右侧为带文字的设置和个人退出；牌桌及弹层从控制栏下方开始。
- 牌局底部采用玩家摘要、单行横滑手牌、右侧操作坞三列结构；667×375 下自适应手牌宽约 40–44px、间隔约 2px、字形不小于约 22px，首屏约 9–10 张并保留横滑。操作按钮按可用空间自适应，不设置全局固定 48px。
- 登录、大厅和牌局弹层在安全区内独立滚动，关键标题与确认操作保持吸顶或吸底。
- 声明面板全端统一为系统智能预选：亮鱼整组调整、暗坎数量直选、手牌单行预览，手机候选区可横滑。
- 所有尺寸采用同一套精简中央布局：八层象形牌堆固定居中偏上并在顶层显示准确余量，待响牌固定在同轴偏下位置；庄标和定庄牌只显示在庄家姓名旁。
- 桌面端保持牌桌布局；声明和出牌交互与移动端统一，服务端协议和规则不变。

## 交互约束

- 点击手牌只更新选中项，重复点击或双击均不出牌；右侧操作坞未选牌时显示禁用的“先选牌”，选牌后显示高亮“出牌”，确认后动画和消息发送同时开始。
- 将牌和金条不可选；阶段或手牌变化后清理失效选择，服务端拒绝时保留有效选择供玩家重试。
- 二级设置分别提供“我的牌”和“桌面牌”的大字/自适应/长牌模式，默认均为自适应并本地持久化；旧 simple/full 偏好迁移为桌面牌大字/长牌。
- 二级设置提供顺时针（下家在左）和逆时针（下家在右），默认逆时针；切换只镜像本地左右座位相关视觉，不改变服务器座位与规则顺序。
- 触摸设备使用横向惯性滚动和按压反馈，不应用粘滞 hover。
- 系统软键盘方向不可由网页控制，因此锁定竖屏时优先提供随机昵称和历史昵称快捷入口。

## 验收矩阵

- 375×667：旋转为 667×375 有效画布，无方向遮罩且可点击。
- 667×375、740×360、844×390：紧凑横屏布局，关键字号清晰，单行大字手牌、右侧确认出牌和完整操作坞无重叠。
- 1024×768、1280×720：桌面/平板布局无回归。

# 麻将布局与三档自适应

新增 `mahjong` 实际布局，保留 `adaptive` 为默认选项，继续读取已有有效偏好。

自适应使用 `useResponsiveViewport` 提供的有效可视宽高（手机竖屏旋转后），依次判断：

| 条件 | 实际布局 |
| --- | --- |
| 宽 < 640px 或高 < 350px | 紧凑 |
| 宽 ≥ 960px 且高 ≥ 440px | 经典 |
| 其余 | 麻将 |

普通手机如 667×375、844×390 和 932×430 使用麻将，极小屏如 568×320 使用紧凑，PC 如 1024×768 使用经典。固定布局不会随窗口变化。沿用 180ms 防抖和动画完成后应用布局的机制。

麻将桌四边保留玩家身份，明示牌组靠内，四条流水按出牌者方位围绕中央牌堆和响应牌。对家牌面转 180°，左右转 ±90°，身份文字保持正向。流水仍通过接收者 ID 连接既有出牌、响应和动画逻辑。旋转牌面分配对应的实际占用尺寸，飞牌匹配旋转后的最终牌面与落点。

流水换行并在区域内滚动；新增流水自动滚到最新一张。自己的手牌和操作栏保持在下方。全部皮肤、牌型以及单排和翻页手牌沿用原偏好。

验证入口：`mahjong-appearance.spec.ts` 覆盖阈值、持久化、方向、拥挤牌桌和横竖屏；`appearance.spec.ts` 覆盖全皮肤及全部布局。继续运行流水稳定性、中央抽牌、旁观、吃碰和减少动态效果回归。

大量吃牌补充验收：逐个座位使用 12 组明示牌（36 张），检查四种代表尺寸、两种牌型和逐组可达性；手机竖屏验证真实触摸滚动，并验证翻页手牌的完整触摸区域。

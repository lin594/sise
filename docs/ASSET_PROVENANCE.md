# 素材来源与许可证

项目整体采用 [AGPL-3.0](../LICENSE)。维护者于 2026-09-10 在 [Issue #33 的确认评论](https://github.com/lin594/sise/issues/33#issuecomment-5613001439) 明确：音频自行录制，SVG 等由 Codex 生成，项目整体使用 AGPL-3.0。该结论替代此前“倾向采用、待确认”的记录。

## 逐项清单

[机器可读清单](asset-provenance.json) 保留原盘点基线、全部 53 个图片/图标/音频文件的路径和 SHA-256，并补入维护者确认链接。许可证覆盖项目代码及随仓库分发的项目素材；来源描述与许可记录分开保存，不把制作工具名称当成权利人。

| 类别 | 来源与记录 |
|---|---|
| 6 条原始互动音频 | 维护者 lin594 自行录制，原件位于 `assets/audio/quick-phrases/` |
| 6 条网页音频副本 | `scripts/sync-quick-phrases.mjs` 从原件复制；内容哈希一致，沿用原录音来源与许可证 |
| 3 张皮肤 SVG | 维护者使用 Codex 生成；设计参考见 [APPEARANCE.md](APPEARANCE.md) |
| favicon、PWA 图标、分享图 | 项目视觉资源；SVG 的生成方式由维护者确认。PNG/ICO 与 SVG 的同批变更见 `7284429`、`33a3aec`、`fccb01d`；不推断未记录的导出工具或参数 |
| 验证截图 | `docs/validation/` 中项目界面的验收记录；具体贡献和版本见所在目录及 Git 历史 |

三张皮肤的材质和空间设计参考 electroxiao 贡献版提交 `156a6ba`，继续保留这一来源说明。文化页的认牌示意由项目 HTML/CSS 和文字绘制。

## 后续维护

新增或替换素材时记录原始来源、制作人或生成方式、许可证及必要署名；更新原件、生成副本和清单哈希。未来导入第三方素材时单列其许可证和署名，不直接套用本次对既有项目素材的确认。

本轮未修改任何音频或图像文件。清单中没有新的授权决策待办；未逐项保存的制作人员或导出参数属于来源记录粒度，不再误写成“等待作者确认”。

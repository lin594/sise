## 维护者确认流程

在 [许可证与素材任务 #33](https://github.com/lin594/sise/issues/33) 分别记录：

1. 代码许可证的最终名称、版本及适用范围。未最终确认前不加入 LICENSE，也不在 README 宣称已经采用。
2. 每项素材作者或权利人、原始来源、是否原创、明确许可文本或授权记录、使用/修改/分发范围及署名要求。
3. 不能确认的项目继续标记待处理，保留素材，不擅自删除或假定允许商用。
4. 若替换素材，更新源文件、所有生成副本、清单哈希及来源记录。新音频必须先补明确来源再扩展。

清单中的 SHA-256 用于核对具体文件版本，不代表许可证。确认后逐项更新作者、允许范围、状态及证据，不能仅批量把“待确认”改成“已授权”。

文化页 `client/public/culture.html` 的认牌示意采用本仓库 HTML/CSS 与文字绘制（AI 辅助生成代码），没有导入外部图片；这项生成过程不构成对现有音频、皮肤或分享图原始授权的确认。

# 三分钟教学演练

大厅的“第一次玩？3 分钟学会”建立独立 practice 房。教学手牌刻意缩短，保留完整 117 张物理牌的唯一性；普通房仍按正式规则发牌。教学场景不接受客户端牌序、seed、手牌或调试状态，生产环境也不依赖 debug_setup。

学习路径：看颜色与字 → 看中央待响应牌 → 抓 → 吃红车马炮 → 弃白仕 → 碰绿马（同时解释三张遇第四张为开）→ 弃白炮 → 胡黄车马炮 → 阅读正常结算。碰和胡来自共享规则引擎的实际候选与执行校验，没有客户端预写结果。教学演练后提供“自己练一局 / 邀请朋友”。本场景实际执行碰，开通过短文解释；坎转开的执行另有规则回归测试。

进度保存在服务端私有快照，仅学习者可读；刷新同房可以恢复，其他访客仍受单人房限制。临时断线不由机器人替学习者出牌，仍遵守房间既有空房清理期限；没有浏览器持久存储时可完成当前演练，但刷新不能保证找回身份。多人响应沿用同一轮询机制，教学窗口为 120 秒；超时或选择其他合法走法可重新演练，重启更新决策键，旧动作不能应用到新场景。

主动退出会销毁教学房与上下文；普通“下一局”入口由教学完成后的两个入口替代。提示只要求服务端当前允许的动作，等待阶段显示等待提示。教学统计使用固定 tutorial 维度，单独汇总，不计普通首局激活、复玩或个人战绩。辅助提示使用 aria-live 与原有键盘操作，不阻挡牌桌。

自动化覆盖正常引擎闭环、恢复、禁用存储、键盘及三种尺寸。真机、实际读屏与地方玩家交叉核对仍未完成；“3 分钟”是入口文案和设计目标，不是已验证的实测学习时长。

# 外观与牌桌布局

皮肤与布局使用独立的浏览器偏好，不发送到房间协议。皮肤负责颜色、字体和装饰；布局负责牌区位置与响应式尺寸。游戏状态、操作和牌面组件共用。

全局设置在大厅及牌局均可打开，现有显示、辅助和提醒偏好继续保留。长条牌采用两端椭圆轮廓，牌堆、暗牌和飞牌统一红色牌背。

新用户、缺少或损坏的偏好字段默认使用 **荔城水乡 + 自适应布局**；已有有效选择保持不变。自适应、经典、紧凑三种布局选择均可搭配所有皮肤；实际渲染仍为经典或紧凑。

经典布局参考贡献版的围桌空间组织，左右席位位于桌面外围，流水在内侧，中央用于牌堆与待响应牌；紧凑布局保留原有分区。布局切换等待现有飞牌及定庄表现结束，保留选择状态并重新测量牌区。

现有超小视口判定（有效宽度 <= 720 或有效高度 <= 380）下，经典布局用户会在大厅或房间等待时看到非阻塞推荐。点击“切换紧凑布局”才会切换；“暂不调整”不会改变布局。提示关闭状态持久保存，存储受限时在当前会话保存。

## 地域皮肤

- 荔城水乡：古荔、古桥、水纹；暖纸、墨绿和荔枝红。
- 莆仙古厝：红砖、燕尾脊、窗棂；砖红、米白和深木色。
- 湄洲海韵：抽象岛屿、帆影、潮纹；海蓝、沙白和暖金。

`client/public/skins/` 中的 SVG 为本项目原创示意装饰，不是地标测绘或外部图片转载。设计选择性参考 electroxiao 贡献版（源提交 `156a6ba`）的桌面材质、纸牌表现与空间组织；未迁入其旧版游戏逻辑。

## 大厅与昵称

普通访问直接进入大厅；昵称优先使用本地当前昵称，再用最近历史昵称，否则自动生成。点顶部昵称可修改，保存后更新本地及游客档案，取消不改变姓名。三个玩法卡片均为直接行动入口，不再先选择再点开始。

房间恢复优先于普通大厅；`new=1` 跳过旧会话恢复。邀请链接自动沿用本机昵称或生成昵称加入，仍须按既有规则选座和准备。昵称和外观不会改变房间身份或权限。游客档案请求异步执行，存储受限仍可在当前会话游戏。
设置按场景分级：大厅、等待和结算使用外观、牌桌与纸牌、声音与提醒、辅助功能四个分类；出牌和声明先显示我的牌、轮到我提醒、规则与全部设置。两种入口共用同一份偏好，二级页面可返回，关闭后焦点回到设置入口。

听牌详情在独立桌面层显示，选中可听牌自动展示，已有听牌可点击“听”查看。五秒后收起，详情滚动或触摸延长展示；键盘焦点位于详情内时不自动关闭。操作区不再承载听牌列表。红色牌背根据大字／长牌模式使用对应轮廓。

所有界面表面、文字、选中状态和提示使用配对的语义颜色。深色皮肤显式声明深色原生控件，地域皮肤声明浅色控件，不随系统偏好改变已选皮肤。`theme-readability.spec.ts` 在系统深浅偏好下逐一检查四皮肤的设置分类、规则、大厅、声明、记录、互动及结算文字对比度。


自适应布局保存为 `adaptive`，有效视口宽度不超过 720 或高度不超过 380 时渲染紧凑布局，其余渲染经典布局；旋转后的有效视口参与判定。已有经典／紧凑选择继续有效。只有明确选择经典的小屏用户收到推荐。

经典布局采用连续桌布和木质桌沿，席位、明牌、流水直接摆放，不显示区域面板框。地域景物留在桌外。中央响应牌不再附带“待响”标签；八张牌只在水平方向错开，每张牌的垂直中心均与牌堆中心对齐。飞牌期间暂存布局与牌形改变，完成后应用并重测几何，红色背面与正面保持相同的大字／长牌轮廓。

## 回归证据

`appearance.spec.ts` 覆盖四皮肤 × 三种布局选择 × 五种代表视口，检查选牌保留、操作可达及八张牌各自的垂直中心误差（不超过 1 CSS 像素）。`central-draw.spec.ts` 检查大字／长牌飞牌落点；`friend-room-usability.spec.ts` 实际点击验证 28 个听牌候选不遮挡出牌、内部滚动和键盘聚焦保留。截图随 CI Playwright 工件保存。

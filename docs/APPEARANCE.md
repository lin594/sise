# 外观与牌桌布局

皮肤与布局使用独立的浏览器偏好，不发送到房间协议。皮肤负责颜色、字体和装饰；布局负责牌区位置与响应式尺寸。游戏状态、操作和牌面组件共用。

全局设置在大厅及牌局均可打开。莆仙长牌是薄纸窄角，两端有牌字，经典桌按相反方向排列。莆仙牌堆、暗牌和飞牌共用朱砂花枝牌背，其他皮肤沿用各自外观。

新用户、缺少或损坏的偏好字段默认使用 **莆仙古厝 + 自适应布局**；已有有效选择保持不变。自适应、经典、紧凑、麻将四种布局选择均可搭配所有皮肤；自适应按有效视口选择经典、麻将或紧凑布局。

经典布局参考贡献版的围桌空间组织，左右席位位于桌面外围，明牌朝内、流水靠所属席位外侧，中央用于牌堆与待响应牌；紧凑布局保留原有分区。布局切换等待现有飞牌及定庄表现结束，保留选择状态并重新测量牌区。

现有超小视口判定（有效宽度 <= 720 或有效高度 <= 380）下，经典布局用户会在大厅或房间等待时看到非阻塞推荐。点击“切换紧凑布局”才会切换；“暂不调整”不会改变布局。提示关闭状态持久保存，存储受限时在当前会话保存。

## 地域皮肤

- 荔城水乡：古荔、古桥、水纹；暖纸、墨绿和荔枝红。
- 莆仙古厝：桌外保留红砖、燕尾脊和窗棂；牌桌使用墨青织面、深木窄沿和木名签，桌上保留砖红与暖纸色的牌面和操作。
- 湄洲海韵：抽象岛屿、帆影、潮纹；海蓝、沙白和暖金。

`client/public/skins/` 中的 SVG 为本项目原创示意装饰，不是地标测绘或外部图片转载。设计选择性参考 electroxiao 贡献版（源提交 `156a6ba`）的桌面材质、纸牌表现与空间组织；未迁入其旧版游戏逻辑。

## 大厅与昵称

普通访问直接进入大厅；昵称优先使用本地当前昵称，再用最近历史昵称，否则自动生成。点顶部昵称可修改，保存后更新本地及游客档案，取消不改变姓名。三个玩法卡片均为直接行动入口，不再先选择再点开始。

房间恢复优先于普通大厅；`new=1` 跳过旧会话恢复。邀请链接自动沿用本机昵称或生成昵称加入，仍须按既有规则选座和准备。昵称和外观不会改变房间身份或权限。游客档案请求异步执行，存储受限仍可在当前会话游戏。
大厅、等待房间直接进入外观、布局、纸牌、声音与提醒、辅助功能五个设置分类；声明、出牌、结算也直接进入设置分类，记录、规则、互动与托管保留在顶栏。牌桌布局和顺逆时针放在“设置 → 布局”；长期牌形习惯放在“设置 → 纸牌”。共用同一份偏好，二级页面可返回，关闭后焦点回到设置入口。临时静音仅影响当前会话。记录、互动和规则面板保留关闭入口，不再提供返回设置按钮；设置内不显示轮到你操作和返回出牌提示。

听牌详情在独立桌面层显示，选中可听牌自动展示，已有听牌可点击“听”查看。五秒后收起，详情滚动或触摸延长展示；键盘焦点位于详情内时不自动关闭。操作区不再承载听牌列表。红色牌背根据大字／长牌模式使用对应轮廓。

所有界面表面、文字、选中状态和提示使用配对的语义颜色。深色皮肤显式声明深色原生控件，地域皮肤声明浅色控件，不随系统偏好改变已选皮肤。`theme-readability.spec.ts` 在系统深浅偏好下逐一检查四皮肤的设置分类、规则、大厅、声明、记录、互动及结算文字对比度。


自适应布局保存为 `adaptive`，按旋转后的有效视口判定。宽度低于 640 或高度低于 350 时用紧凑布局，宽度至少 960 且高度至少 440 时用经典布局，其余使用麻将布局。已有经典／紧凑选择继续有效。只有明确选择经典的小屏用户收到推荐。

经典布局采用连续桌布和木质桌沿，席位、明牌、流水直接摆放，不显示区域面板框。地域景物留在桌外。中央响应牌沿用原牌桌落点，来源签区分牌堆摸出和当前出牌者。八张牌只在水平方向错开，每张牌的垂直中心均与牌堆中心对齐。飞牌期间暂存布局与牌形改变，完成后应用并重测几何，红色背面与正面保持相同的大字／长牌轮廓。

## 回归证据

`appearance.spec.ts` 覆盖四皮肤 × 四种布局选择 × 五种代表视口，检查选牌保留、操作可达及八张牌各自的垂直中心误差（不超过 1 CSS 像素）。`central-draw.spec.ts` 检查大字／长牌飞牌落点；`friend-room-usability.spec.ts` 实际点击验证 28 个听牌候选不遮挡出牌、内部滚动和键盘聚焦保留。截图随 CI Playwright 工件保存。莆仙桌实装与基线截图见 [牌桌验收](validation/paper-table/README.md)。

## 莆仙同席牌带

三家的公开明组和余牌背共用各自席位的牌带。余牌背取公开剩余张数，空间不足时先压叠；手牌清空的席位仍可查看公开组。小屏超出空间的明组可横滑，流水在独立牌区。牌桌自适应在空间足够时显示双头长牌，超小屏自适应优先大字，显式选择和结算的牌式可读性保留。开局与中盘实装见[牌桌拟真验收](validation/table-fidelity/README.md)。

## 移动端密度与可读性

经典布局的两处上方流水分别扩展至左上、右上角并在圆角木框内保留安全内距，左右席位位于中排；下方流水向桌内收，中央明牌区使用约 52% 桌宽。仅保留圆角、牌面高亮和动画必要间距。左右席位将明牌放在身份信息下方并居中对齐，牌面分数保留在无障碍摘要中；对家保留庄标并省去翻庄牌缩略图，避免首行明牌被挤出。控制栏直接呈现在桌布上，取消整条底色及分隔线，按钮保留独立背景和至少 44px 的高度。

流水完整保留，不再截取最后 8/14 张。先换行，再适度缩小至牌字至少 10px；超出区域后局部滑动；停在末尾时跟随新牌，正在翻看旧牌时保留阅读位置。单行手牌按完整牌数缩放后一屏显示全部，不显示或预留翻页按钮及页码，小屏允许继续缩小牌字与点击区域。翻页模式保留原尺寸、至少 14px 牌字及 28×44px 点击区域，溢出时可滑动和翻页。紧凑布局的小屏流水也省去可见标题，方向归属保留在无障碍标签中。移动端不显示常驻滚动条，以边缘渐隐和手牌翻页控制提示剩余内容；电脑端使用细圆角滚动条。桌面牌面尺寸设有上限，不随宽屏无限放大。

`mobile-table-appearance.spec.ts` 覆盖密集手牌、四处长流水、多组明牌、四皮肤声明标记，以及手机横竖屏和 1024×768、1280×720、1440×900、1920×1080 大屏。流水全部访问、真实点击尺寸和标记对比度纳入断言；旋转后的真实触摸滑动由 Chromium CDP 验证。


自动排列会按可用尺寸调整。568×320 和 667×375 保持原尺寸翻页，844×390 可以一次看完整手牌。玩家可在「设置 → 纸牌 → 手牌排列」手动选择单行或翻页。

### 长辈版

从大厅或牌桌顶部点「长辈版」即可开启，开关状态会随本机保存。手牌和来牌用大字显示；手牌放不下时可滑动，也可点前翻、后翻逐页查看。选中红俥后，确认按钮显示「出红俥」。改选另一张会同步更新按钮，只有按下确认才实际出牌。展开内屏有充足空间时，12 至 22 张牌按从左到右、从上到下的顺序分两行显示。再次点「长辈版」恢复原先的牌型与排列。可查看[同一局在三种手机尺寸上的实装画面](validation/phone-readability/README.md)。

### 全局颜色辅助

颜色辅助开启时，牌名与颜色字共用牌面内部的阅读区：保留一个完整牌名，颜色字位于玩家阅读方向的右下角；极短牌面把颜色字放在牌名旁的空角，避免继续缩小牌名。关闭后恢复长条牌的双端牌名。阅读区随牌框反向旋转，辅助字在四边流水和飞牌中保持方向一致。

辅助开关不改变手牌、明示牌、流水或响应牌的外部尺寸，麻将牌组也不因辅助字增高。开启辅助时明示牌取消横向叠压，避免后一张牌遮住前一张的角标；牌组沿用现有换行与滚动区域。密集牌组仍按既有规则换行、缩放与滚动。`mahjong-appearance.spec.ts` 覆盖四种布局 × 两种牌型，以及 640×350、568×320、667×375、375×667、844×390、1024×768、1440×900，测量实际字形范围、辅助字边界和操作栏遮挡，并检查开关前后牌面尺寸一致。

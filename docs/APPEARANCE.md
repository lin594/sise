# 外观与牌桌布局

皮肤与布局使用独立的浏览器偏好，不发送到房间协议。皮肤负责颜色、字体和装饰；布局负责牌区位置与响应式尺寸。游戏状态、操作和牌面组件共用。

全局设置在大厅及牌局均可打开，现有显示、辅助和提醒偏好继续保留。长条牌采用两端椭圆轮廓，牌堆、暗牌和飞牌统一红色牌背。

本系列分步交付；基础提交只开放已经实现的赛博极简和紧凑布局。

设置按场景分级：大厅、等待和结算使用外观、牌桌与纸牌、声音与提醒、辅助功能四个分类；出牌和声明先显示我的牌、轮到我提醒、规则与全部设置。两种入口共用同一份偏好，二级页面可返回，关闭后焦点回到设置入口。

听牌详情在独立桌面层显示，选中可听牌自动展示，已有听牌可点击“听”查看。五秒后收起，详情滚动或触摸延长展示；键盘焦点位于详情内时不自动关闭。操作区不再承载听牌列表。红色牌背根据大字／长牌模式使用对应轮廓。
